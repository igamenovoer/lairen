# Project Context

Durable project knowledge for agents and developers. User-facing documentation
lives in `docs/`; this tree holds working context.

- `plans/`: implementation, migration, refactor, and investigation plans.
- `features/`: requirements, use cases, interface designs, and handoffs.
- `design/`: goals, architecture, system design, and technical decisions.
- `summaries/`: synthesized findings from investigations or sessions.
- `archived/`: superseded material retained for reference.
